Slicer Pause & Swap Instructions

Works on ANY 3D printer! In Bambu Studio, OrcaSlicer, PrusaSlicer, or Cura, slice your file with 100% rectilinear infill, then right-click the layer slider and add a Pause / Filament Change at these exact heights:

Slot Filament Color Target Feature Start Height Est. Weight
🔑 Crucial Slicer Settings:
  • Layer Height: Match your chosen height (0.08mm or 0.12mm)
  • First Layer Height: 0.20mm
  • Infill: 100% (Rectilinear) — no hollow interior!
  • Wall Loops: 1 or 2
